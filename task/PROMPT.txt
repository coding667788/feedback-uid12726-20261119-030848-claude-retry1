实现离线事件导出。原始事件包含租户、事件类型和 JSON 值；版本化规格包含派生列，每列为 JSON Pointer 取值、连接字符串或定长掩码，后两者固定引用若干源字段，不允许任意表达式，支持派生列之间引用。仅当同一角色授权该事件类型及该输出列的所有传递原始路径才可发布，所有全局封锁优先，按解码后的段匹配。数组仅允许整体读取，数组内任一子路径封锁即封锁整数组。

单次导出把输入事件、角色和策略版本固定为一个快照。可选列不满足则省略，必需列不满足则拒绝该事件；两个同名冲突的导出列、派生环和缺依赖的规格整版拒绝。错误、排序和审计只记录规格中已配置的路径与原因，禁止引用未授权的实际键名、值或内容摘要。用成对输入仅改变未授权枝的键名与值，验证完整导出及日志一致；另测角色不能拼接、间接派生、转义数字字典键与数组、已授权 null 与缺失。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
